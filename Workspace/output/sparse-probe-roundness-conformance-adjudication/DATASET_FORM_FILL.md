# Dataset creation form — fill-in

## Dataset name

```
Sparse-Probe Circular Feature Inspection Records
```

## Overview

A corpus of coordinate-measuring-machine inspection records for circular features on machined parts.
Each record is one inspected feature — a bore, shaft, counterbore, journal or seat — with the probe
coordinates taken around it in the machine frame, the drawing nominal diameter and roundness
tolerance, the reference roundness deviation of the surface, the conformance outcome against the
drawing, and the machine / set-up signature class of the production run.

Production inspection plans are deliberately sparse: four to eleven probed points per feature.
Features belonging to the same part were produced in one set-up on one machine, and different
features of a part may carry different probe counts.

The corpus is procedurally generated by `generate.py`, which is uploaded alongside the data. Its
spectral model is calibrated against published measured roundness traces (see **Source**).

## File structure

After upload the platform shows `generate.py` at the top level and extracts the archive into a
`raw_upload/` directory:

```
generate.py
raw_upload/
  features.csv     one row per inspected circular feature
  points.csv       one row per probed point
  README.txt       provenance and column dictionary
  LICENSE.txt      licence of this corpus
```

This build: 53,954 features, 385,210 probed points, 12,000 parts, 900 machines, 14 MB extracted and
5.2 MB as the uploaded archive.

## features.csv columns

| Column | Type | Description |
|---|---|---|
| `machine_index` | int | Machine / set-up identifier |
| `part_index` | int | Part identifier |
| `feature_index` | int | Feature within the part |
| `feature_kind` | string | bore, shaft, counterbore, journal, seat |
| `n_probe` | int | Probed points on this feature |
| `nominal_diameter_mm` | float | Drawing nominal diameter, mm |
| `roundness_tol_um` | float | Drawing roundness tolerance, um |
| `ront_um` | float | Roundness deviation, um |
| `conform` | int | 1 when within tolerance, else 0 |
| `signature_class` | string | Machine / set-up signature class |

`ront_um` is the peak-to-valley of the least-squares-circle profile after the ISO 12181-2 Gaussian
filter with a 15 undulations-per-revolution cutoff, evaluated on a 360-point grid.

`signature_class` takes one of `three_jaw_chuck`, `clamp_ovality`, `spindle_bearing_order`,
`centreless_five_lobe`, `fine_ground_smooth`, `worn_tool_chatter`.

## points.csv columns

| Column | Type | Description |
|---|---|---|
| `part_index` | int | Part identifier |
| `feature_index` | int | Feature within the part |
| `point_index` | int | Point number on this feature |
| `x_mm` | float | Probe x coordinate, mm |
| `y_mm` | float | Probe y coordinate, mm |

Coordinates are in the machine frame. The feature centre is offset from the frame origin by the
set-up centring error, so a circle fit is required before any form deviation can be read.

## Source

Generated by the uploaded `generate.py`. No third-party data is redistributed.

The generator's spectral model is calibrated against a published measured dataset, cited here for
attribution and for verification of the physics:

Tiainen, T. (2022). *Roundness Measurement Dataset*. Zenodo. https://doi.org/10.5281/zenodo.7004548 —
CC BY 4.0. Taylor Hobson Talyrond TR31c traces of five roundness reference workpieces, 3600 points
per revolution, ISO 12181-2 Gaussian filter with a 15 UPR cutoff. Fitted amplitude envelope
`amplitude ~ C * k^alpha` with `alpha = -1.935`; dominant undulation orders 1, 2, 3 and 5; one
discrete order spike at 12; per-workpiece peak-to-valley roundness from 19.9 to 307.5 micrometres.

## Notes

Default settings (`--machines 900 --parts 12000`) produce about 54k features and 385k probed points,
roughly 14 MB extracted and 5.2 MB as the uploaded archive. The generator is deterministic given its
`--seed`. Scale is controlled with `--machines` and `--parts`; both scale the output linearly, and
even a ten-fold increase stays far inside the upload budget.

Roundness values in this build run from 0.3 to 343 micrometres with a median of 7.5 and a first
percentile of 0.8. The overall conformance rate is 0.48, and it stays between roughly 0.35 and 0.76
across the whole tolerance ladder, so the tolerance value on its own does not decide the outcome.
Probe counts are balanced across 4, 5, 6, 7, 8, 9 and 11 points per feature, and the six signature
classes each hold between 5.2k and 6.5k features.
