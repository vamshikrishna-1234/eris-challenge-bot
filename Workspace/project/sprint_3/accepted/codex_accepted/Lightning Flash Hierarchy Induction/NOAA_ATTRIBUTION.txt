Source data: NOAA GOES-16 Geostationary Lightning Mapper Level-2 Lightning Detections product, accessed through NOAA Open Data Dissemination Program / NOAA Open Data on AWS.

This archive contains five untouched official NOAA NetCDF source files used by the Lightning Flash Hierarchy Induction challenge. The files were downloaded byte-for-byte from the official NOAA noaa-goes16 public bucket URLs listed in URL_IMPORT_LIST.txt.

NOAA attribution is requested for redistribution of unaltered data. NOAA does not endorse this challenge. Prepared challenge cases, if generated by prepare.py, are modified derivatives and are not included in this raw-source archive.
