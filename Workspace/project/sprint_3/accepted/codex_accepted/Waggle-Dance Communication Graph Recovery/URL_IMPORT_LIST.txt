# Preferred raw-source upload

Preferred path: run the local helper and upload the resulting clean ZIP.

```powershell
python build_source_subset_zip.py --staging official_raw_subset --output waggle_dance_raw_subset.zip
```

Upload:

```text
waggle_dance_raw_subset.zip
```

This clean ZIP contains the official CSV files below plus unchanged extracted date-level members from `Berlin2019_tracks.zip` for:

