# Novelty and difficulty note

The platform originality pass on 2026-07-15 identified EASG, PVSG, Event-Graph VITG, Action Genome, and later VidSRL/VidSitu when an attempted title used "video activity graph prediction". Those titles/prose over-signaled generic video event-graph or semantic-role labeling. The visible challenge has therefore been reframed as `Opaque Security Clip Action Ledger Recovery`, while keeping the same prepared data and grader. The scored object is described as a compact hidden action ledger: frame-span records with agent/action/context/role tuples plus audit links for documented coupling, overlap, and adjacency.

Closest public benchmark family after this revision: video scene-graph and action-scene-graph generation. The genuine distinction is that this challenge does not ask for object boxes, panoptic masks, object-object predicates, open-vocabulary relation triplets, captions, or long egocentric scene narratives. It asks for a source-derived operational ledger with canonical ordering, frame-bin spans, a finite activity-state tuple vocabulary, strict malformed-output handling, CPU-only constraints, and held-out recording-session robustness. Detector-plus-relationship proposals transfer only as a feature extractor; they do not directly produce the canonical ledger state space, audit-link taxonomy, row-local validation contract, or session-weighted score.

Conditional novelty judgment: 6/10 if the participant-visible title and opening paragraphs keep the ledger-recovery contract central and explicitly rule out scene-graph/PVSG-style object-relation generation. The challenge would fall back into the adapted 4-5/10 band if it is described merely as video event graph generation or if the ledger state/link reconstruction is reduced to activity classification, captioning, detector differencing, or generic visual relationship prediction.
