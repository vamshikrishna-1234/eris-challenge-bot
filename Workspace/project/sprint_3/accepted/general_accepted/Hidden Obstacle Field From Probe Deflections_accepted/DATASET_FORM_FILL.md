# Dataset creation form — fill-in

## Dataset name

```
Synthetic Probe-Deflection Arena Clips With Hidden Obstacle-Field Labels
```

## Overview

A self-rendered corpus of short top-down videos of probe balls bouncing inside a square arena that hides a small field of solid obstacles. Each obstacle is made of one or more whole 12×12 grid cells and is rendered the same colour as the floor, so it is invisible; its presence is revealed only by how the balls deflect and by brief contact flashes. Every clip is accompanied by exact labels — the full 12×12 occupancy map, the number of distinct obstacles, and the first-hit row of a fresh straight-down probe in a designated un-shown column. All geometry, motion (exact closed-form tile reflection, no physics engine), and rendering are procedurally generated with a small NumPy + Pillow software renderer; there are no external assets.

## File structure

```
videos/<scene_hash>.mp4   one rendered arena clip per row of scenes.csv
scenes.csv                one row per clip: inputs, labels, and metadata tags
```

* `videos/` holds the H.264 MP4 clips, each `480 x 480`, `12` FPS, `90` frames (about 7.5 seconds).
* `scenes.csv` has one row per clip.

## scenes.csv columns

Each row of `scenes.csv` describes exactly one rendered clip, with these columns:

* `scene_hash` (string): stable per-clip hash; matches the mp4 name.
* `video` (string): relative path to the clip's mp4 (`videos/<scene_hash>.mp4`).
* `base_scenario_id` (string): id of the underlying scenario, shared by its variants.
* `variant` (string): which rendered variant — one of `base`, `relight`, or `mirror`.
* `num_probes` (int): number of probe balls launched in the clip.
* `query_port` (float): x-coordinate, in grid units, of the un-shown query column.
* `layout_family` (string): obstacle-layout family tag — one of `sparse`, `spread`, `cluster`, or `dense`.
* `floor_style` (string): floor / colour render-style tag.
* `occupancy_json` (string): 144-character row-major 0/1 grid (row 0 = top, col 0 = left).
* `n_obstacles` (int): number of distinct 4-connected obstacles.
* `query_hit_row` (int): first-hit row in the query column, or -1 if it is clear.

## Source

Fully synthetic. Generated by a self-contained Python script that simulates each probe with exact closed-form axis-aligned (tile) reflection and renders the arena with a dependency-free top-down software renderer (NumPy + Pillow), muxed to H.264 via imageio. No external datasets, models, or assets are used.

## Notes

* Defaults yield roughly 700 clips (about 240 base scenarios × up to 3 variants), totalling a few hundred MB — well under typical upload limits and the 5–6 GB budget.
* Each base scenario is rendered as up to three deterministic variants (`base`, `relight`, `mirror`); the mirror variant flips the layout, ports, and labels together so answers stay in the observed frame.
* Layout families (`sparse`, `spread`, `cluster`, `dense`) and floor styles are balanced across the corpus, and `num_probes` is sampled independently of `n_obstacles`.
