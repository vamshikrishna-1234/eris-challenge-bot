# Switch-Lamp Intervention Panel Clips (SLIP-Panel)

## Overview

This dataset is a collection of short synthetic video clips of a control panel with a row of switches and a row of lamps. Each lamp is driven by a hidden Boolean gate over a subset of the switches. A scripted sequence of switch flips is applied to each panel; after each flip the lamps settle and the panel is recorded, so the clip shows the switch positions and lamp states evolving step by step. Every frame is procedurally rendered from a controlled circuit, so the recording carries no external imagery. The data is fully synthetic and original.

## File Structure

- `scenes.csv` - one row per clip with the circuit parameters and labels.
- `videos/` - one MP4 per clip, named `<scene_hash>.mp4`.

The default generated corpus contains 800 clips (800 rows in `scenes.csv`, 800 MP4 files in `videos/`).

## Columns (scenes.csv)

- `scene_hash` (string) - unique clip identifier and video filename stem.
- `n_switches` (integer) - number of switches on the panel, 3 to 6.
- `n_lamps` (integer) - number of lamps on the panel, 3 to 6.
- `flip_log_json` (string) - JSON list whose entries are lists of switch ids flipped at each step.
- `query_config` (string) - JSON list of 0/1 switch values for the held-out query configuration.
- `wiring_json` (string) - JSON object mapping each lamp id to its `gate` and `inputs` (switch ids).
- `query_pattern` (string) - JSON list of 0/1 lamp states under `query_config`.
- `init_config_json` (string) - JSON list of 0/1 initial switch positions (also visible in the clip).
- `circuit_family` (string) - coarse grouping label (`ca`, `cb`, `cc`).
- `variant` (string) - sub-variant label (`a`, `b`).
- `ood_axis` (string) - scene-family tag (`none`, `xor_heavy`, `multi_input`, `sparse_interventions`).
- `render_style` (string) - visual style tag (`panelA`, `panelB`).

## Types

Integer: `n_switches`, `n_lamps`. String: `scene_hash`, `flip_log_json`, `query_config`, `wiring_json`, `query_pattern`, `init_config_json`, `circuit_family`, `variant`, `ood_axis`, `render_style`.

## Source

Generated by a self-contained NumPy + Pillow renderer that draws the switch toggles and lamps for each settled state, then encodes the frame sequence to H.264 with imageio. The circuit wiring, the flip script, and every lamp state are sampled and computed from seeded random states, so the corpus is fully reproducible and contains no real-world imagery.

## Notes

Resolution is 480x320 at 10 FPS; each settled state is held for several frames so switch and lamp states are clearly readable. The default run yields 800 clips at roughly 25 MB total, far under the platform size budget; diversity comes from the number of scenes, not from resolution. Gate selection keeps each lamp's on-rate in a balanced band so neither all-on nor all-off is a useful guess. All cells are populated (no missing data).
